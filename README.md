# 🚖 Uber ETL Pipeline Data Engineering Project

An end-to-end Data Engineering project that demonstrates how to build a scalable ETL pipeline using Uber trip data. The project covers data extraction, transformation, loading (ETL), cloud storage, data modeling, SQL analytics, and workflow automation to generate business insights from ride-sharing data.

---

# 📌 Project Overview

This project showcases a complete ETL workflow for processing Uber trip data. It extracts raw data, performs data cleaning and transformation, loads the processed data into a data warehouse, and executes analytical SQL queries to uncover valuable business insights.

The project demonstrates modern data engineering practices including workflow automation, cloud-based storage, dimensional data modeling, and analytical reporting.

# 📊 Data Model

The project uses a dimensional data model consisting of fact and dimension tables to optimize analytical query performance.

Typical dimensions include:

- Date Dimension
- Time Dimension
- Passenger Count
- Trip Distance
- Pickup Location
- Drop-off Location
- Payment Type
- Rate Code
